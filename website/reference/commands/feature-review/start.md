Use `xpd feature-review start` in the [recorded feature review](../../feature-review/#recorded-stages).

Commit the manifest and adapter dependencies before starting. Supply an adapter for implemented features. A hypothesis-only run can start without one.

## Example

```console
$ xpd feature-review start --help
Start a run: record the commit it starts from, the paths, line count, checks and optional benchmark of the project
...
```
