Record the plan of a round. The file holds the fixes in the order to make them, each with the ids of the findings it removes, and the findings that are right as they are, each with a reason. xpd refuses a plan that names a finding the ledger of today does not have, a fix with no finding, and a plan while a fix is still open.

The [`xpd untangle`](../../untangle/#a-recorded-run) page shows a whole run.

## Example

```console
$ xpd untangle plan --help
...
```
