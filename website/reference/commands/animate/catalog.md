List Manim Community Module Index families or compare every sibling primitive in one family side by side without starting Python or Podman.

## Examples

```console
$ xpd animate catalog indication --json | jq -c '.symbols | length >= 8'
true
```

## Exit status

| Exit code | Meaning |
| --- | --- |
| 0 | The catalog or matching family was printed |
| 2 | No Manim module family matched the requested name |
