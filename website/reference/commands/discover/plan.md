Record an ordered list of fixes and any findings or checklist answers that have a reason. Name a finding ID or set a supported goal for each fix. A design goal names checklist items in `questions`. Under `answered`, give each item a verdict of `pass`, `na` or `accepted` and a reason.

Run `xpd discover plan plan.json`.

## Example

```console
$ xpd discover plan --help | sed -n '/^Usage:/p'
Usage: xpd discover plan [OPTIONS] <FILE>
```
