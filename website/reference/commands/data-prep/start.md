Record the baseline commit, paths, checks, optional adapter and target. Use a clean commit. An already open run requires `--restart` to replace it.

See the [recorded run](../../data-prep/#a-recorded-run) for how to use `xpd data-prep start`.

## Example

```console
$ xpd data-prep start --help
Start a run: record the commit it starts from, the paths, line count, checks and optional benchmark of the project
...
```
