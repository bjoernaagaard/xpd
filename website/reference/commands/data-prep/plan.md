Record `fixes`, `accepted` finding exceptions and `answered` checklist verdicts. Pass a JSON file or `-` for standard input.

See the [recorded run](../../data-prep/#a-recorded-run) for how to use `xpd data-prep plan`.

## Example

```console
$ xpd data-prep plan --help
Record the plan of a round: the fixes in order, and the findings that are right as they are.
...
```
