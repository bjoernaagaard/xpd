Use `xpd ts-review finish` in the [recorded time series review](../../ts-review/#a-recorded-run).

Close the run after every fix and checklist item is settled and every new finding has a reason.

## Example

```console
$ xpd ts-review finish --help
End the run: compare findings, line count and benchmark timing with the start commit. Exit 1 while a fix is open or a new finding has no reason
...
```
