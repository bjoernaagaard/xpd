Use `xpd ts-review start` in the [recorded time series review](../../ts-review/#a-recorded-run).

Record a clean baseline, paths, checks and an optional adapter. Use `--restart` to replace an unfinished run.

## Example

```console
$ xpd ts-review start --help
Start a run: record the commit it starts from, the paths, line count, checks and optional benchmark of the project
...
```
