Use `xpd ts-review plan` in the [recorded time series review](../../ts-review/#a-recorded-run).

Record fixes, accepted findings, and checklist answers. Use `-` in place of the plan file to read JSON from stdin.

## Example

```console
$ xpd ts-review plan --help
Record the plan of a round: the fixes in order, and the findings that are right as they are.
...
```
