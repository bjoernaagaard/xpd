Use `xpd opt-review start` during a [recorded optimization review](../../opt-review/#recorded-stages).

Commit the selected paths and any Python adapter. Add project solution checks with repeated `--check` options. The ledger records the baseline before edits.

## Example

```console
$ xpd opt-review start --help | head -n 1
Start a run: record the commit it starts from, the paths, line count, checks and optional benchmark of the project
```
